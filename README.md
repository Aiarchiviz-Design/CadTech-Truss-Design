Automating Truss Design & Quick Take-Off with CAD and AI-Truss-Design!
https://aitrussdesign.ai.studio/
Designing structural roof trusses can often be a repetitive and time-consuming process. To bridge the gap between architectural layouts and structural framing, I’ve built an open-source project: AI-Truss-Design!This tool is designed to help drafts people, structural engineers, and designers streamline layout generation and geometry processing.
1. Upload 2D Roof plan in "DXF"
2. Click "Generate complete roof"
3. Click "Analyze all trusses"
4. Download Trusses Report and Take-off
